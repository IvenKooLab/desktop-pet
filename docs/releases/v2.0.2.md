# Comi Pet v2.0.2 — urgent: restore legacy hook paths

v2.0.2 is an urgent compatibility fix: the v2.0.0 rename left existing host hook configurations pointing at scripts that no longer exist, so ZCode / Codex / OpenCode bridges failed on every hook invocation.

### Downloads

| File | Platform | How to run |
| --- | --- | --- |
| `ComiPet-v2.0.2-windows-x64.zip` | Windows x64 | Unzip and run `ComiPet.exe`; no Python needed |
| `ComiPet-v2.0.2-macos-universal.zip` | macOS 13+, Apple Silicon / Intel | Unzip and open `ComiPet.app`; no Python or compiler needed |
| `SHA256SUMS.txt` | All | SHA-256 checksums for both archives |

The macOS build is ad-hoc signed and not notarized, so Gatekeeper may warn about an unidentified developer: right-click the app and choose Open, or run `xattr -d com.apple.quarantine ComiPet.app`. You can also build from source following the README.

### Who needs this

- **ZCode / Codex / OpenCode hook users:** v2.0.0 renamed `iven_hook.py` and friends to `comi_hook.py`, but host configurations still point at the old paths, so every hook invocation failed with `can't open file .../iven_hook.py`. The old paths are restored as pure delegation shims — **after `git pull` the hooks work again with no configuration change at all** (you may also switch the config to `comi_hook.py`; both stay supported).
- **Inside-DSH users:** after restarting DSH and refreshing the browser page, the right-click menu follows the desktop grouping (everyday / work themes / little breaks), and flicking Comi flies her on a parabola, bouncing off the viewport edges and settling with a squash — the same physics constants as the desktop app.

### Verified

- `tests/test_legacy_shims.py`: a real ZCode hook payload sent through the legacy `iven_hook.py` path produces the correct unified event in the inbox (`kind=turn.started`, `source=zcode`); the other shims are checked to be pure delegation.
- 135 tests pass in total; 51 DSH overlay checks pass.

### Upgrade

- Hook users: `git pull` (or re-clone); no configuration changes.
- The app itself has no binary changes; download this package only if you want the update prompt to go away.
- Data directory rules are unchanged: the legacy `~/.iven-pet` keeps being used.
