Comi Pet v2.0.2 紧急修复：v2.0.0 改名后老用户的宿主钩子集体失效的问题。

### 谁需要这版

- **ZCode / Codex / OpenCode 钩子用户**：v2.0.0 把 `iven_hook.py` 等脚本改名为 `comi_hook.py`，但宿主配置仍指向旧路径，每次 Hook 调用都会报 `can't open file .../iven_hook.py`。本版恢复旧路径为纯委托垫片——**`git pull` 后钩子立即恢复，配置一行都不用改**（想改也可以：把 `iven_hook.py` 换成 `comi_hook.py`，两者长期并存）。
- **DSH 界面内用户**：重启 DSH 并刷新浏览器页面后，右键菜单变成与桌面端一致的分组样式（日常互动 / 工作状态 / 生活小动作），并且拖拽 Comi 快速一甩会抛物线飞行、撞视口边缘反弹、落地弹跳（Q 弹挤压），与桌面端同一套物理常量。

### 验证

- tests/test_legacy_shims.py：旧路径 `iven_hook.py` 收到真实 ZCode Hook stdin → 收件箱出现正确统一事件（kind=turn.started、source=zcode）；其余垫片静态校验纯委托。
- 全套 135 项测试通过；DSH overlay 51 项检查通过。

### 升级

- 钩子用户：`git pull`（或重新 clone）即可，无需改配置。
- 桌宠程序本身无二进制变更；如需更新提示消失，下载本版安装包替换即可。
- 数据目录规则不变：旧 `~/.iven-pet` 自动沿用。

**English:** v2.0.2 is an urgent compatibility fix: v2.0.0's rename left old hook configs pointing at deleted scripts (`iven_hook.py` → `can't open file`), breaking ZCode/Codex/OpenCode bridges. Legacy paths are restored as pure delegation shims — after `git pull`, hooks work again with zero config changes. The DSH web overlay also gains the grouped right-click menu and fling physics matching the desktop app. 135 tests pass, including a real stdin replay through the legacy shim.
