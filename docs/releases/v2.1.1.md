## Changelog

v2.1.1 fixes sleep, manual playback and dragging inside DSH, keeps custom data directories consistent across the app and plugin, and helps new users discover how to interact with Comi.

### Downloads

| File | Platform | How to run |
| --- | --- | --- |
| `ComiPet-v2.1.1-windows-x64.zip` | Windows x64 | Unzip and run `ComiPet.exe`; no Python needed |
| `ComiPet-v2.1.1-macos-universal.zip` | macOS 13+, Apple Silicon / Intel | Unzip and open `ComiPet.app`; no Python or compiler needed |
| `SHA256SUMS.txt` | All | SHA-256 checksums for both archives |

The macOS build is ad-hoc signed and not notarized, so Gatekeeper may warn about an unidentified developer. You can also build from source following the README.

### Fixes

1. **Sleep and manual actions inside DSH.** Choosing Sleep now keeps Comi asleep until you wake or drag her. With autoplay paused, a manually selected action finishes and returns to idle. Holding a drag no longer briefly switches to a random action; routine host status updates no longer interrupt manual playback or flight.
2. **Custom data directories.** The desktop app, DSH event bridge and chat now share the same `COMI_HOME` / legacy `IVEN_HOME` precedence, so they can find each other when you choose a custom data root. Existing `~/.iven-pet` data continues to be used automatically.
3. **First-run hints that disappeared unseen.** The hint waits until the pet is visible and no harness notice is taking priority, and is marked as read only after it is shown. Starting with the pet pinned in place also displays the hint.
4. **Clearer setup instructions.** Adapter examples now consistently use `__COMI_REPO__`. Disconnect messages and both READMEs describe the current lease expiry of about 60 seconds.

### New

- A one-time interaction hint on macOS and Windows: click, drag, fling and right-click to open the menu.
- A quick-start table for connecting coding assistants, plus a contributor guide, issue templates and a development dependency list.

### Upgrade

- Quit the old app, then replace `ComiPet.app` or `ComiPet.exe`. Existing configuration and data are retained; no migration is needed.
- **DSH users must also update the plugin.** Update the repository and the installed `adapters/dsh/comi-bridge` directory, restart DSH and refresh its page. A symlinked plugin follows the repository update; a copied installation needs the complete updated plugin directory. The desktop ZIPs do not include adapters. See the [DSH setup guide](https://github.com/IvenKooLab/desktop-pet/blob/v2.1.1/adapters/dsh/README.md).

## 更新日志

Comi Pet v2.1.1 修复「DSH 界面内」的睡眠、手动播放和拖拽控制，统一桌宠与插件的自定义数据目录，并为新用户补上首次玩法提示。

### 修复

1. **DSH 内嵌睡眠与手动动作**：选择睡觉后保持睡眠，直到主动唤醒或拖动。暂停轮播时，点播动作仍会正常结束并回到待机；长时间按住拖拽不再短暂切入随机动作，普通宿主状态更新也不会打断手动动作或飞行。
2. **自定义数据目录不同步**：桌宠、DSH 事件桥接与对话统一遵循 `COMI_HOME` / 旧名 `IVEN_HOME` 的优先级，避免自定义目录下互相收不到消息。已有 `~/.iven-pet` 数据继续自动沿用。
3. **首次提示没看到就消失**：提示会等待桌宠可见且没有宿主提醒占用时再展示，实际展示后才记为已读；固定位置启动也能看到。
4. **接入说明更准确**：适配器示例统一使用 `__COMI_REPO__` 占位符；断线提示和中英文 README 同步当前约 60 秒的租约到期时间。

### 新增

- macOS 与 Windows 首次玩法提示：单击、拖拽、甩出，以及右键打开菜单；展示一次后不再打扰。
- 编码助手接入速查表、贡献指南、问题模板与开发依赖清单。

### 升级

- 退出旧版后替换 `ComiPet.app` 或 `ComiPet.exe`，已有配置与数据继续沿用，无需迁移。
- **DSH 用户还需更新插件**：更新仓库及已安装的 `adapters/dsh/comi-bridge` 目录，再重启 DSH、刷新页面。符号链接安装随仓库更新，复制安装需重新复制完整插件目录。桌宠 ZIP 不包含适配器，详见 [DSH 接入说明](https://github.com/IvenKooLab/desktop-pet/blob/v2.1.1/adapters/dsh/README.md)。
- macOS 包为临时签名、未做 Apple 公证，系统可能提示无法验证开发者。
