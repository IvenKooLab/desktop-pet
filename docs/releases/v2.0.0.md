> **Comi Pet v2.0.0 —— 她有自己的名字了。**
>
> 从这一版起，这只桌宠正式叫 **Comi（可米）**。她最早是 [comfy-agent](https://github.com/IvenKooLab/comfy-agent)（ComfyUI 桌面工作台）的工具图标，后来才慢慢长出动作、长成一只桌宠——名字里的 "Com" 就来自那段出身。

### 下载与运行

| 文件 | 平台 | 使用方式 |
| --- | --- | --- |
| `ComiPet-v2.0.0-windows-x64.zip` | Windows x64 | 解压后运行 `ComiPet.exe`，无需安装 Python |
| `ComiPet-v2.0.0-macos-universal.zip` | macOS 13+，Apple Silicon / Intel | 解压后打开 `ComiPet.app`，无需 Python 或编译工具 |
| `SHA256SUMS.txt` | 通用 | 两个安装包的 SHA-256 校验值 |

Mac 包采用临时签名，未做 Apple 公证，系统可能提示无法验证开发者：右键 App 选"打开"，或执行 `xattr -d com.apple.quarantine ComiPet.app`。

### 从 v1.x 升级（老用户请看这段）

- **直接替换程序即可**：Mac 删掉旧的 `IvenPet.app`、换成 `ComiPet.app`；Windows 用 `ComiPet.exe` 替换 `IvenPet.exe`。
- **配置、对话记忆、事件历史全部保留**：程序会自动识别旧数据目录 `~/.iven-pet` 并继续使用，不需要手动迁移；只有全新安装才会创建 `~/.comi-pet`。
- **旧环境变量仍生效**：`COMI_*` 优先，未设置时回退到 `IVEN_*`，你那边的脚本和 CI 不用急着改。
- **DSH 适配器需重装一次**：插件包已改名为 `comi-bridge`，重新安装新包后旧的 `iven-bridge` 目录可以删掉（两者不共存，避免重复接收事件）。

### 本版更新

**角色与品牌**

- 角色定名 **Comi（可米）**，窗口标题、气泡署名、右键菜单、文档统一更新。
- 安装包 `IvenPet` → `ComiPet`，DSH 适配器 `iven-bridge` → `comi-bridge`，环境变量 `IVEN_*` → `COMI_*`（旧名兼容）。

**更好用的菜单**

- 右键菜单按类分组：顶层只留「说话 · 动作 ▸ · 陪伴 ▸ · 语言 ▸ · 关于与更新 ▸」，动作再分日常互动 / 工作状态 / 生活小动作三级，空分类不显示。二十多项平铺的长菜单没有了。

**新版本会通知你了**

- 启动约 4 秒后静默检查 GitHub Release（只读跳转地址，不传任何本机内容）：发现新版就气泡提示，右键多出"下载新版本 vX…"，也可手动"检查更新…"；不想要就在菜单里关掉。

**手感与陪伴**

- 甩抛物理：抓起 Comi 快速一甩，她会抛物线飞出去、撞屏幕边缘反弹、落地弹跳几下才停稳（Mac 落地有 Q 弹挤压）；温柔放下还是原地停住。
- 系统通知：任务完成、出问题、等你确认时弹原生通知。默认只在桌宠藏进 DSH 界面时才打扰，可切"总是/关闭"。
- 位置记忆：拖到哪，下次启动就在哪。
- 本机控制接口：其他插件或命令行可以让她说话、点播动作、查状态（`python tools/comi_cli.py say "休息一下"`），零网络零端口。

**新动作**

- 四个生活小动作：困倦眨眼、委屈表情、挥手庆祝、左右观察——全部由已验收的原始帧编排，没有改动角色造型与配色。
- 素材生产线：新增提示词配方与一键打包工具，未来加新动作有据可依。

### 仍有限制

- 不支持跟随你正在使用的 **Codex 桌面会话**；Claude Code、Cursor、OpenCode 适配器仍需各自实际客户端验收。
- Linux 未提供原生透明后端；Windows 的窗口顶边行走等平台交互仍建议实机确认。
- Mac 包临时签名、未公证。

完整记录见 [CHANGELOG.md](https://github.com/IvenKooLab/desktop-pet/blob/v2.0.0/CHANGELOG.md)。

**English:** v2.0.0 gives the pet her own name: **Comi** (可米), after the tool icon of [comfy-agent](https://github.com/IvenKooLab/comfy-agent), a ComfyUI desktop workbench, where she started out.

Upgrading from v1.x is a straight swap — the app detects the legacy `~/.iven-pet` data directory and keeps your config, chat memory and event history; the old `IVEN_*` environment variables still work as a fallback. Reinstall the DSH adapter once under its new name (`comi-bridge`).

This release also brings a grouped right-click menu (Actions / Companion / Language / About, instead of twenty-plus flat entries), opt-out update checks against GitHub releases, fling physics with damped bounces and a squash on landing, native notifications for completed/failed/approval-needed events, window-position memory, a local file control API, and four new life actions choreographed from already-approved frames. Mac builds are ad-hoc signed and not notarized. Active Codex desktop sessions are still not supported; Linux has no native transparent backend yet.
