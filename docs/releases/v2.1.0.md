## Changelog

v2.1.0 fixes three problems in the "inside DSH" mode and brings the in-page right-click menu and fling feel in line with the desktop app.

### Downloads

| File | Platform | How to run |
| --- | --- | --- |
| `ComiPet-v2.1.0-windows-x64.zip` | Windows x64 | Unzip and run `ComiPet.exe`; no Python needed |
| `ComiPet-v2.1.0-macos-universal.zip` | macOS 13+, Apple Silicon / Intel | Unzip and open `ComiPet.app`; no Python or compiler needed |
| `SHA256SUMS.txt` | All | SHA-256 checksums for both archives |

The macOS build is ad-hoc signed and not notarized, so Gatekeeper may warn about an unidentified developer: right-click the app and choose Open, or run `xattr -d com.apple.quarantine ComiPet.app`. You can also build from source following the README.

### Fixes

1. **The pet popped back to the desktop about two minutes after moving inside DSH.** The lease heartbeat was gated on page visibility — covering or minimising the DSH window made the page hidden, heartbeats stopped and the 30-second lease expired. The tab that owns the lease now renews regardless of visibility; the lease is extended to 60 seconds and the sanity caps on all three sides to 90 seconds. Verified with continuous heartbeats over 150 seconds (well past the original failure point), and the pet still returns to the desktop about a minute after the heartbeats stop (the recovery path when DSH really dies is preserved).
2. **A broken image icon during flings.** The flight frames `fall_0`/`land_0` were missing from the web frame whitelist, so the whole flight rendered a broken image. They are whitelisted now, and the image element falls back to the idle frame if any frame fails to load.

### New

- **The in-page right-click menu now matches the desktop menu in hierarchy and language:** Move to desktop · Actions ▸ (everyday / work themes / little breaks, plus sleep and wake) · Companion ▸ (display mode ✓, autoplay ✓) · Language ▸ (system default / 简体中文 / English, sharing the preference file with the desktop app) · About & updates ▸ (version, GitHub).
- **Web-side fling physics:** the same constants as the desktop app — parabola, viewport-edge bounces, a squash on landing, and a gentle release that simply stops in place.

### Upgrade

- Replace the app, restart the DSH desktop application once and refresh the browser page (the in-page menu and physics load with the page).
- Data directories and configuration are unchanged; nothing to migrate.

## 更新日志

Comi Pet v2.1.0 集中修复「DSH 界面内」模式的三个问题，并把界面内的右键菜单与甩抛手感对齐桌面端。

### 修复

1. **放进 DSH 后约两分钟自己弹回桌面**：租约续期心跳被页面可见性拦截（DSH 窗口被遮挡/最小化 → 页面 hidden → 心跳停止 → 30 秒租约到期）。现在持有租约的页面无论窗口是否可见都持续续租；租约延长到 60 秒，三端校验上限同步到 90 秒。实测持续心跳 150 秒全程稳定，心跳停止后约 1 分钟正常回桌面（DSH 真正关闭时的回收机制保留）。
2. **甩抛时显示裂图**：飞行动画帧 fall_0/land_0 不在 Web 帧服务白名单内，404 导致飞行全程裂图。已入白名单，且图片加载失败自动回落待机帧。

### 新增

- **界面内右键菜单与桌面端同层级同语言**：移到独立桌面 · 动作 ▸（日常互动/工作状态/生活小动作 + 睡觉/唤醒）· 陪伴 ▸（显示模式 ✓ / 自动轮播 ✓）· 语言 ▸（跟随系统/简体中文/English，与桌面端共用偏好文件）· 关于与更新 ▸（版本号/GitHub）。
- **Web 端甩抛物理**：与桌面端同一套常量（抛物线、视口边缘反弹、落地 Q 弹挤压、温柔放下原地停住）。

### 升级

- 替换程序并重启一次 DSH 桌面应用、刷新浏览器页面（Web 菜单与物理随页面加载）。
- 数据目录与配置完全沿用，无需迁移。

**English:** v2.1.0 fixes the embedded-DSH mode popping back to the desktop after ~2 minutes (lease heartbeats stopped while the DSH window was hidden; renewals now ignore visibility, lease extended to 60s with 90s sanity caps), fixes the broken-image icon during web fling physics (fall/land frames are now served, plus an onError fallback), and brings the DSH overlay menu to full parity with the desktop app — same hierarchy, same language preference, with a new language endpoint — plus web-side fling physics using the exact same constants. Swap the app, restart DSH once, refresh the browser page.
