## Changelog

From this release the pet is called **Comi (可米)**. She began life as the tool icon of [comfy-agent](https://github.com/IvenKooLab/comfy-agent), a ComfyUI desktop workbench, and slowly grew actions until she became a desktop pet — the "Com" in her name comes from that origin.

### Downloads

| File | Platform | How to run |
| --- | --- | --- |
| `ComiPet-v2.0.0-windows-x64.zip` | Windows x64 | Unzip and run `ComiPet.exe`; no Python needed |
| `ComiPet-v2.0.0-macos-universal.zip` | macOS 13+, Apple Silicon / Intel | Unzip and open `ComiPet.app`; no Python or compiler needed |
| `SHA256SUMS.txt` | All | SHA-256 checksums for both archives |

The macOS build is ad-hoc signed and not notarized, so Gatekeeper may warn about an unidentified developer: right-click the app and choose Open, or run `xattr -d com.apple.quarantine ComiPet.app`. You can also build from source following the README.

### Upgrading from v1.x

- **Just replace the app.** On macOS delete the old `IvenPet.app` and use `ComiPet.app`; on Windows replace `IvenPet.exe` with `ComiPet.exe`.
- **Configuration, chat memory and event history are kept.** The app detects the legacy data directory `~/.iven-pet` and keeps using it, with nothing to migrate by hand; only a fresh install creates `~/.comi-pet`.
- **The old environment variables still work.** `COMI_*` wins, and `IVEN_*` is used as a fallback, so scripts and CI do not have to change immediately.
- **Reinstall the DSH adapter once.** The plugin package is now `comi-bridge`; after installing the new package the old `iven-bridge` directory can be removed (they must not run together, or events would be duplicated).

### What's new

**Character and branding**

- The character is now called **Comi (可米)**: window title, bubble signature, right-click menu and documentation all updated.
- Packages move from `IvenPet` to `ComiPet`, the DSH adapter from `iven-bridge` to `comi-bridge`, and environment variables from `IVEN_*` to `COMI_*` (old names still read).

**A better menu**

- The right-click menu is grouped: the top level keeps only Talk · Actions ▸ · Companion ▸ · Language ▸ · About & updates ▸, with Actions split into everyday / work themes / little breaks. Empty categories are hidden. The twenty-plus flat entries are gone.

**Update notices**

- About four seconds after launch the pet silently checks the GitHub release feed (it only reads the redirect target and uploads nothing). When a newer version exists it shows a bubble, adds "Download vX…" to the menu, and offers a manual "Check for updates…" item; it can be switched off in the menu.

**Feel and company**

- Fling physics: grab Comi and flick — she flies on a parabola, bounces off the screen edges and settles after a few bounces (with a squash on macOS); a gentle release just drops in place.
- System notifications for completed, failed and approval-needed events. By default they only appear while the pet is hidden inside DSH; "always"/"off" are available.
- Position memory: she comes back where you left her.
- A local control API: other plugins or the command line can make her talk, play an action or read live state (`python tools/comi_cli.py say "take a break"`), with zero network and zero ports.

**New actions**

- Four life actions — sleepy blink, feeling down, celebrate, look around — all choreographed from approved original frames without touching the character's shape or palette.
- An asset pipeline: prompt recipes plus a one-command packaging tool, so new actions have a documented path.

![Comi keeping you company while you work](https://raw.githubusercontent.com/IvenKooLab/desktop-pet/v2.0.0/docs/images/bridge-zcode-working.png)

### Limitations

- Following an active **Codex desktop session** is not supported; the Claude Code, Cursor and OpenCode adapters still need acceptance on the real clients.
- Linux has no native transparent backend. Windows platform interactions (walking on window edges) still deserve a hands-on check.
- The macOS build is ad-hoc signed and not notarized.

### 下载与运行

| 文件 | 平台 | 使用方式 |
| --- | --- | --- |
| `ComiPet-v2.0.0-windows-x64.zip` | Windows x64 | 解压后运行 `ComiPet.exe`，无需安装 Python |

Mac 包采用临时签名，未做 Apple 公证，系统可能提示无法验证开发者：右键 App 选"打开"，或执行 `xattr -d com.apple.quarantine ComiPet.app`。

### 从 v1.x 升级（老用户请看这段）

- **直接替换程序即可**：Mac 删掉旧的 `IvenPet.app`、换成 `ComiPet.app`；Windows 用 `ComiPet.exe` 替换 `IvenPet.exe`。
- **配置、对话记忆、事件历史全部保留**：程序会自动识别旧数据目录 `~/.iven-pet` 并继续使用，不需要手动迁移；只有全新安装才会创建 `~/.comi-pet`。
- **旧环境变量仍生效**：`COMI_*` 优先，未设置时回退到 `IVEN_*`，你那边的脚本和 CI 不用急着改。
- **DSH 适配器需重装一次**：插件包已改名为 `comi-bridge`，重新安装新包后旧的 `iven-bridge` 目录可以删掉（两者不共存，避免重复接收事件）。

### 本版更新

**角色与品牌**

- 角色定名 **Comi（可米）**，窗口标题、气泡署名、右键菜单、文档统一更新。
- 安装包 `IvenPet` → `ComiPet`，DSH 适配器 `iven-bridge` → `comi-bridge`，环境变量 `IVEN_*` → `COMI_*`（旧名兼容）。

**更好用的菜单**

- 右键菜单按类分组：顶层只留「说话 · 动作 ▸ · 陪伴 ▸ · 语言 ▸ · 关于与更新 ▸」，动作再分日常互动 / 工作状态 / 生活小动作三级，空分类不显示。二十多项平铺的长菜单没有了。

**新版本会通知你了**

- 启动约 4 秒后静默检查 GitHub Release（只读跳转地址，不传任何本机内容）：发现新版就气泡提示，右键多出"下载新版本 vX…"，也可手动"检查更新…"；不想要就在菜单里关掉。

**手感与陪伴**

- 甩抛物理：抓起 Comi 快速一甩，她会抛物线飞出去、撞屏幕边缘反弹、落地弹跳几下才停稳（Mac 落地有 Q 弹挤压）；温柔放下还是原地停住。
- 系统通知：任务完成、出问题、等你确认时弹原生通知。默认只在桌宠藏进 DSH 界面时才打扰，可切"总是/关闭"。
- 位置记忆：拖到哪，下次启动就在哪。
- 本机控制接口：其他插件或命令行可以让她说话、点播动作、查状态（`python tools/comi_cli.py say "休息一下"`），零网络零端口。

**新动作**

- 四个生活小动作：困倦眨眼、委屈表情、挥手庆祝、左右观察——全部由已验收的原始帧编排，没有改动角色造型与配色。
- 素材生产线：新增提示词配方与一键打包工具，未来加新动作有据可依。

![Comi 在工作时陪着你](https://raw.githubusercontent.com/IvenKooLab/desktop-pet/v2.0.0/docs/images/bridge-zcode-working.png)

### 仍有限制

- 不支持跟随你正在使用的 **Codex 桌面会话**；Claude Code、Cursor、OpenCode 适配器仍需各自实际客户端验收。
- Linux 未提供原生透明后端；Windows 的窗口顶边行走等平台交互仍建议实机确认。
- Mac 包临时签名、未公证。
