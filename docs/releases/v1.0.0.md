# Iven Pet v1.0.0 — first public release

Iven Pet is a 3D plush desktop companion that runs on its own, keeping you company while you work and taking the occasional break. This is the first packaged release for Windows x64 and macOS 13+ (Apple Silicon / Intel).

### Downloads

| File | Platform | How to run |
| --- | --- | --- |
| `IvenPet-v1.0.0-windows-x64.zip` | Windows x64 | Unzip and run `IvenPet.exe`; no Python needed |
| `IvenPet-v1.0.0-macos-universal.zip` | macOS 13+, Apple Silicon / Intel | Unzip and open `IvenPet.app`; no Python or compiler needed |
| `SHA256SUMS.txt` | All | SHA-256 checksums for both archives |

The macOS build is ad-hoc signed and not notarized, so Gatekeeper may warn about an unidentified developer: right-click the app and choose Open, or run `xattr -d com.apple.quarantine IvenPet.app`. You can also build from source following the README.

### What's new

- Keeps the approved Iven 3D plush look; longer animation performances at 75% playback speed.
- Waving, bouncing, clapperboarding, looking around — plus stretching, dozing and a Rubik's cube.
- Four work-companion themes composed from original frames: deep thinking, getting impatient, low token budget, relief. Low budget is a manual performance, not a balance check.
- Local work-status bridging for DSH and ZCode, persistent status bubbles and harness source selection.
- Two display modes — inside DSH or standalone desktop — with automatic recovery to the desktop when the page goes away.
- Chinese/English UI switching that remembers your choice, plus a menu link to the GitHub repository.
- Fixes for Mac ghosting, drag coordinates, bubble placement and multi-source status switching.

![Iven in action](https://raw.githubusercontent.com/IvenKooLab/desktop-pet/v1.0.0/docs/previews/profile-reactions.gif)

### Scope

The "inside DSH" mode needs the adapter installed and DSH reloaded; the standalone app must stay running for the desktop pet to come back after the page closes. Adapter instructions live in `adapters/dsh/README.md` in the source tree. The standalone pet needs no account and no model API.

Following an active Codex desktop session is not supported yet. Claude Code, Cursor and OpenCode still need acceptance on the real clients. The Windows GUI and the actual DSH host still need environment-specific acceptance; automated tests and an isolated-UI acceptance pass are done.

Full history: [CHANGELOG.md](https://github.com/IvenKooLab/desktop-pet/blob/v1.0.0/CHANGELOG.md).

# 中文

Iven Pet 的首个公开打包版本：一只独立运行、陪你工作与摸鱼的 3D 绒质桌宠。

### 下载与运行

| 文件 | 平台 | 使用方式 |
| --- | --- | --- |
| `IvenPet-v1.0.0-windows-x64.zip` | Windows x64 | 解压后运行 `IvenPet.exe`，无需安装 Python |
| `IvenPet-v1.0.0-macos-universal.zip` | macOS 13+，Apple Silicon / Intel | 解压后打开 `IvenPet.app`，无需 Python 或编译工具 |
| `SHA256SUMS.txt` | 通用 | 两个安装包的 SHA-256 校验值 |

Mac 包采用临时签名，未做 Apple 公证，系统可能提示无法验证开发者。也可以下载下方 Source code，按照 README 从源码构建。

### 本版更新

- 保留已确认的 Iven 3D 绒质造型；长段动作轮播和 75% 播放速度。
- 挥手、弹跳、打板、观察，以及伸懒腰、打瞌睡、玩魔方。
- 苦思冥想、等待不耐烦、额度不足、松口气四组原版帧组合演出。额度不足是手动表演，不是余额检测。
- DSH、ZCode 本地工作状态联动，持续气泡与 Harness 来源选择。
- DSH 界面内 / 独立桌面两种模式，页面失联后自动恢复桌面显示。
- 中英文语言切换、记住偏好，以及 GitHub 项目跳转菜单。
- 修复 Mac 残影、拖拽坐标、气泡位置和多来源状态切换等问题。

### 使用范围

DSH 界面内模式需额外安装适配器并重新加载 DSH；独立程序保持运行时才可在页面关闭后恢复。插件使用说明在源码的 `adapters/dsh/README.md`。独立桌宠本身无需账号或模型 API。

当前不支持跟随正在使用的 Codex 桌面会话。Claude Code、Cursor、OpenCode 仍待实际客户端验收。Windows GUI 和 DSH 实际宿主仍需用户环境验收，当前已完成自动测试及隔离界面验收。
