Iven Pet v1.0.1 修复"DSH 界面内"显示切换的失联问题：桌宠不再在选择内嵌后凭空消失几十秒。

### 下载与运行

| 文件 | 平台 | 使用方式 |
| --- | --- | --- |
| `IvenPet-v1.0.1-windows-x64.zip` | Windows x64 | 解压后运行 `IvenPet.exe`，无需安装 Python |
| `IvenPet-v1.0.1-macos-universal.zip` | macOS 13+，Apple Silicon / Intel | 解压后打开 `IvenPet.app`，无需 Python 或编译工具 |
| `SHA256SUMS.txt` | 通用 | 两个安装包的 SHA-256 校验值 |

Mac 包采用临时签名，未做 Apple 公证，系统可能提示无法验证开发者。也可以下载下方 Source code，按照 README 从源码构建。

### 本版更新

- 修复：选择"DSH 界面内"后，如果 DSH 没在运行或网页没打开，桌宠会消失最长 30 秒才回来。现在改为两段式租约——桌宠只在 DSH 网页确认接手显示（认领并写入 client_id）后才隐藏；约 6 秒无人接手会自动回到桌面，并弹出"未连上 DSH：启动 dsh 并打开网页后再试内嵌"的提示。
- 已在内嵌模式下关闭 DSH 网页时，桌宠按租约到期（最长 30 秒）自动恢复桌面显示，行为不变。
- README（中/英）新增桥接工作状态实拍截图。

![跟随 ZCode 工作中的 Iven：状态气泡显示来源、任务标签与当前步骤](https://raw.githubusercontent.com/IvenKooLab/desktop-pet/v1.0.1/docs/images/bridge-zcode-working.png)

### 升级与兼容

- 直接替换旧版即可，配置无需迁移；DSH 适配器插件无需更新（认领/心跳协议向后兼容）。
- 其余行为与 v1.0.0 一致：不包含桌宠制作器，Linux 暂不支持；不支持跟随正在使用的 Codex 桌面会话；Claude Code、Cursor、OpenCode 适配器仍待实际客户端验收。

完整记录见 [CHANGELOG.md](https://github.com/IvenKooLab/desktop-pet/blob/v1.0.1/CHANGELOG.md)。

---

**English:** v1.0.1 fixes the embedded-DSH display handoff: the desktop pet no longer vanishes for up to 30 seconds when DSH is not running. The pet now hides only after the DSH web page claims the display lease; if nothing claims it within ~6 seconds it stays on the desktop and shows a hint. Existing DSH adapters remain compatible — just replace the app. Mac builds are ad-hoc signed and not notarized. Active Codex desktop sessions are still not supported; see the README and changelog for details.
