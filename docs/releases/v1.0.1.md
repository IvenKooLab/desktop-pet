# Iven Pet v1.0.1 — fix the embedded-DSH handoff

v1.0.1 fixes the embedded-DSH display handoff: the pet no longer vanishes for up to 30 seconds when DSH is not running.

### Downloads

| File | Platform | How to run |
| --- | --- | --- |
| `IvenPet-v1.0.1-windows-x64.zip` | Windows x64 | Unzip and run `IvenPet.exe`; no Python needed |
| `IvenPet-v1.0.1-macos-universal.zip` | macOS 13+, Apple Silicon / Intel | Unzip and open `IvenPet.app`; no Python or compiler needed |
| `SHA256SUMS.txt` | All | SHA-256 checksums for both archives |

The macOS build is ad-hoc signed and not notarized, so Gatekeeper may warn about an unidentified developer: right-click the app and choose Open, or run `xattr -d com.apple.quarantine IvenPet.app`. You can also build from source following the README.

### What's fixed

- Choosing "inside DSH" when DSH was not running (or its page was closed) used to hide the pet for up to 30 seconds. The handoff is now a two-phase lease: the pet hides only after the DSH page claims the display (claiming it and writing `client_id`); if nothing claims it within ~6 seconds the pet returns to the desktop with a hint to start DSH first.
- Closing the DSH page while embedded still restores the desktop pet when the lease expires (30 seconds at most).
- The README (both languages) gained a real screenshot of the bridge status card.

![Iven following ZCode while working: the status bubble shows the source, task label and current step](https://raw.githubusercontent.com/IvenKooLab/desktop-pet/v1.0.1/docs/images/bridge-zcode-working.png)

### Upgrade and compatibility

- Replace the previous version; no configuration migration is needed. The DSH adapter plugin does not need updating — the claim/heartbeat protocol is backward compatible.
- Everything else matches v1.0.0: no pet maker, no Linux support yet, active Codex desktop sessions are not followed, and the Claude Code / Cursor / OpenCode adapters still await real-client acceptance.

Full history: [CHANGELOG.md](https://github.com/IvenKooLab/desktop-pet/blob/v1.0.1/CHANGELOG.md).

### 本版更新

- 修复：选择"DSH 界面内"后，如果 DSH 没在运行或网页没打开，桌宠会消失最长 30 秒才回来。现在改为两段式租约——桌宠只在 DSH 网页确认接手显示（认领并写入 client_id）后才隐藏；约 6 秒无人接手会自动回到桌面，并弹出"未连上 DSH：启动 dsh 并打开网页后再试内嵌"的提示。
- 已在内嵌模式下关闭 DSH 网页时，桌宠按租约到期（最长 30 秒）自动恢复桌面显示，行为不变。
- README（中/英）新增桥接工作状态实拍截图。

![跟随 ZCode 工作中的 Iven：状态气泡显示来源、任务标签与当前步骤](https://raw.githubusercontent.com/IvenKooLab/desktop-pet/v1.0.1/docs/images/bridge-zcode-working.png)

### 升级与兼容

- 直接替换旧版即可，配置无需迁移；DSH 适配器插件无需更新（认领/心跳协议向后兼容）。
- 其余行为与 v1.0.0 一致：不包含桌宠制作器，Linux 暂不支持；不支持跟随正在使用的 Codex 桌面会话；Claude Code、Cursor、OpenCode 适配器仍待实际客户端验收。
