# WALK 素材规范 · Walk Asset Spec

> **状态：工程实现冻结。** 当前最大阻塞不是 AnimationClip，而是 Walk 素材的视觉一致性。
> 在 Walk Sheet 通过 4 帧一致性压力测试之前：**不修改 pet.py、不实现 AnimationClip、不接入任何新帧**。

---

## 1. 固定规范（不可协商）

1. Walk 动画固定为**纯右侧面视角**（不允许 3/4、不允许正面、不允许视角变化）
2. 单一 camera（位置/焦距完全不变）
3. 单一角色比例（Q版 3.5 头身）
4. 单一 ground line（四/八帧脚底同一水平基准线）
5. 8-frame cycle
6. Contact / Down / Passing / Up × 2（左右腿交替）
7. 12 fps
8. 左侧朝向通过水平镜像生成，不单独维护另一套素材
9. 不允许每帧重新设计角色（刘海/眼睛/耳机/服装/鞋子锁死）
10. 不允许运行时偷偷缩放素材（尺寸不一致在导入期 FAIL，不静默修正）

### 角色身份锁（生成时必须逐项锁死）

淡紫白色短发 · 原有刘海形状 · 紫色大眼睛 · 青蓝色头戴式耳机 ·
紫色连帽卫衣 · 深色短裤 · 紫白色运动鞋 · Q版 3.5 头身 · 同脸型同配色

**Walk 不拿场记板**（板会遮挡躯干和手臂摆动）。
场记板仅用于：Happy / Cheer / Double Click / Special。

## 2. 生成流程：先 4 帧压力测试，PASS 再扩 8 帧

```
Character Master（身份）
      ↓ 豆包 4 帧测试图
5 项验收（视角/头/脚底/耳机/刘海）
      ├─ FAIL → 重新生成 4 帧
      └─ PASS → 扩展 8 帧 → 终验 → 存 walk_master.png → 工程接入
```

**状态：ASSET-FIRST 冻结中。工程实现（AnimationClip）延后至 4 帧 PASS 之后。**

**验收清单（10 项，全部 PASS 才算过）：**

| # | 检查 | PASS 标准 |
|---|---|---|
| A | 视角 | 四帧全部纯右侧面（无 3/4 / 正面 / 视角跳变） |
| B | 头部尺寸 | 四帧一致 |
| C | 耳机 | 尺寸和位置一致 |
| D | 刘海结构 | 四帧同款（A/B/C 变体 = FAIL） |
| E | 脚底基准线 | 四帧同一水平线 |
| F | 角色整体高度 | 四帧一致 |
| G | 身体比例 | 四帧一致 |
| H | 相机/焦距/透视 | 完全一致 |
| I | 真实动作变化 | 必须是真实腿部/手臂动作，而非整体形变 |
| J | 重心变化 | 包含真实腿部/手臂/重心变化 |

### Prompt ① · 4 帧一致性压力测试

```

这是动画资产制作，不是重新设计角色。
【角色一致性要求】
必须是上传图片中的同一个角色：
- 淡紫白色短发
- 原有刘海形状
- 紫色大眼睛
- 青蓝色头戴式耳机
- 紫色连帽卫衣
- 深色短裤
- 紫白色运动鞋
- Q版3.5头身比例
- 完全保持原角色的脸型、发型、耳机、服装和配色
禁止重新设计角色。
【镜头要求——非常重要】
四个姿势必须：
- 完全相同的纯右侧面视角
- 身体朝右
- 摄像机位置完全不变
- 焦距完全不变
- 角色高度完全一致
- 头部大小完全一致
- 脚底在同一条水平基准线上
- 不允许出现3/4视角
- 不允许正面
- 不允许视角变化
- 不允许透视变化
这是二维动画制作的同机位素材。
【动作】
生成4个连续的右侧面行走姿势：
Frame 1：右脚向前的 Contact Pose
Frame 2：身体下沉的 Down Pose
Frame 3：双腿经过身体中线的 Passing Pose
Frame 4：身体抬高的 Up Pose
四帧必须是连续动作。
腿部动作要明显。
手臂与腿自然反向摆动。
身体重心发生自然变化。
头部保持稳定。
头发产生非常轻微的惯性摆动。
【非常重要】
不要生成四个独立角色。
必须像同一个二维动画角色连续改变姿势。
角色设计不能变化。
不要增加任何新饰品。
不要改变衣服。
不要改变耳机。
不要改变鞋子。
不要改变发型。
不要改变头身比例。
不要加入场记板。
纯透明或纯白背景。
四个完整全身角色水平排列。
每个角色之间留出明显间隔。
不要文字。
不要标签。
不要动画时间轴。
不要说明文字。
```

### Prompt ② · 4 帧 PASS 后扩展为 8 帧

```
上一张图片中的角色和镜头设置已经确定。
现在不要重新设计角色。
请在完全相同的角色设计、相同侧面视角、相同摄像机位置、相同画面比例下，将行走循环扩展为完整8帧。
8帧顺序：
1. Contact
2. Down
3. Passing
4. Up
5. Contact - opposite leg
6. Down - opposite leg
7. Passing - opposite leg
8. Up - opposite leg
要求：
这是一个连续的二维动画循环。
所有帧必须：
- 同一个角色
- 同一个纯右侧面视角
- 同样头身比例
- 同样头部大小
- 同样耳机
- 同样发型
- 同样服装
- 同样鞋子
- 同样角色高度
- 同一条脚底基准线
禁止3/4视角。
禁止镜头变化。
禁止角色设计变化。
禁止重新设计服装。
禁止改变发型。
禁止改变耳机。
不要添加场记板。
最终效果应该能够逐帧播放，而不会产生角色闪烁、视角跳变或比例跳变。
```

### Prompt ③ · 模型较弱时的 2+2+2+2 降级方案

先出 Frame A（Contact）+ Frame B（Down），再追加 Frame C（Passing）+ Frame D（Up），
每次都附参考图并强调"与之前帧完全相同的角色/视角/比例/地面线"。
逐对验收后再出反侧（E~H）。
