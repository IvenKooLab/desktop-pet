# SOP · IP 角色桌宠化全流程

> 把任意 IP 角色（Q 版/手办风）做成 Windows 桌面宠物的标准作业流程。
> 本仓库的 Iven Pet 即按此 SOP 产出：从 AI 设定图到桌面双击 exe，全链路约半天。
> 适用前提：Windows + Python 3.8+（运行时零第三方依赖，构建期才需要工具链）。

---

## 总览

```
① 设定图生成（豆包/MJ，人工出图）
      ↓
② 素材切片 + AI 抠图（tools/make_frames3d.py）
      ↓
③ 动作帧合成（同脚本 --frames，品红色键透明）
      ↓
④ 三重自检（qa_frames 数值 + qa_diff 像素回归 + 双底色接触表人工过目）
      ↓  不合格 → 回②调整参数，禁止在成品帧上打补丁
⑤ 运行时状态机（pet.py，tkinter 零依赖）
      ↓
⑥ 打包分发（PyInstaller onefile → 桌面双击 exe）
```

**核心原则：所有质量关卡都在"切图/合成"阶段，成品帧出现破损时禁止对 GIF 打补丁，
必须回源修复重生成**——GIF 是产物，不是素材。

## ① 设定图生成（人工，豆包/MJ 均可）

### 需要出的图（缺一不可）

| 图 | 内容 | 要求 |
|---|---|---|
| 动作表情 Sheet | 6~8 个姿势排开 | 覆盖：待机、走路（左/右朝向各2相位）、开心、害羞、被抓住 |
| 走路循环 Sheet | 同一朝向连续迈步 2~4 帧 | **单人物原图优先**（见②的坑） |
| 待机呼吸 Sheet | 同角度 2~3 张微动 | 呼吸感靠帧间微差 |
| 三视图（可选） | 正/侧/背 | 做"转一圈"彩蛋用 |

### 生成时的坑（每条都真实踩过）

- **假透明 PNG**：平台导出的"透明底"实为 RGB 图、棋盘格画在像素里（无 alpha 通道）。
  验证：`PIL.Image.open(...).mode` 是否 RGBA。假透明用中性色规则可切（见②）。
- **浅色角色 × 浅色/白背景**：白头发、白色鞋底与背景同色系——这是后续抠图
  最难的场景，**宁可让豆包出深色/彩色渐变背景版**，抠图成功率天差地别。
- **同批图比例漂移**：不同批次生成的角色头身比可能差 25%+。同一动作库的图
  尽量一次生成；跨批次的图必须做比例归一（见③）。
- **白条纹/高光细节**：深色道具上的白色细节（如场记板的条纹）在 AI 抠图时
  最容易被打成背景，需③的 fill_holes 回填。

## ② 素材切片 + AI 抠图（`tools/make_frames3d.py`）

### 模式选择（按背景类型）

| 背景类型 | 模式 | 说明 |
|---|---|---|
| 青蓝渐变棚拍底 | `bg="blue"` | 颜色闸门（G-R≥14 & B-G≥5 vs 角色全身≤0）+ 局部梯度洪泛 |
| 白/棋盘格假透明 | `bg="checker"` | 中性浅色规则（max-min≤6 & min≥195），仅当角色无大面积浅白部位 |
| **单人物原图（推荐）** | `bg="rembg"` | AI 抠图，任何背景通吃 |

### rembg 模式的三条铁律（每条背后都是一次返工）

1. **逐人裁切，禁止整张 Sheet 喂模型**。u2net 内部只看 320×320：
   2848px 宽的 Sheet 整张喂入，八宫格里每个人物只分到 ~85px，
   手持道具、鞋子必然糊掉。先粗定位（中性色规则取反即可），
   逐个人物裁出（留 16px padding）单独过模型。
2. **滞后阈值代替单阈值二值化**：白底上的白发、白鞋，u2net 输出低 alpha
   (20~100)，单阈值 127 会把白发成片砍掉。改用强 α≥140 为确定前景、
   弱 α≥25 为候选，`binary_propagation` 从强到弱传播——连体的浅色部位
   被拉回，孤立噪声被弃。
3. **深色部件回收 + 封闭区回填**：AI 偶发丢掉手持的深色道具（场记板）、
   或把道具上的白色细节（条纹）判成背景。前者用颜色回收
   （深蓝紫: max<140 & B≥R，且在前景 35px 近邻内）；后者用
   `binary_fill_holes` 回填封闭区（条纹被板框包围，天然是封闭洞）。

### 组件过滤的双刃剑

切图后通常要滤渣点（保留主组件 + ≥8% 的部件）。**但手持道具（场记板）
与手指的连接处 alpha 很低，道具会断开成独立组件而被误删**。
对策：有手持道具的图，阈值降到 2%，或改走单人物原图直切（`cut_single`）。

## ③ 动作帧合成

- **色键透明**：角色贴到品红 #FF00FF 画布，运行时 `-transparentcolor` 键掉。
- **预乘 alpha 空间**：缩放/旋转前必须先预乘（透明像素 RGB 归零）、
  变换后还原并二值化（α≥160）——否则透明像素残留的底色会混进边缘
  （缩放混蓝底、旋转混黑），成品出现紫/粉描边。
- **比例归一**：不同批次/不同姿势（蜷缩 vs 站立）按 bbox 高度 fit 会互相
  放大缩小。**用头宽做归一基准**（各帧头宽偏差控制在 ±10% 内）；
  缩放必须作用在 fit 之后（fit 前的预缩放会被 thumbnail 抵消）。
- **步态节奏**：两姿势交替的走路循环，帧时长 ≥500ms、步幅 ≈25px 匹配，
  否则双脚快速抽搐。有真迈步 Sheet 就用真帧，别用程序变形。
- **画布级清渣**：合成后清除 <150px 的孤立色块——GIF 调色板量化会把
  细连接路径键断、浮出碎片，这一步是最后一道保险。

## ④ 三重自检（`tools/qa_frames.py` + `tools/qa_diff.py`）

### 数值自检（qa_frames.py）

- 悬浮碎片：前景中与主体分离、面积 > 0.15% 的碎块 → 0 才通过
- 内部孔洞：被前景包围的透明区 > 1% → 0 才通过
- 尺寸一致性：头宽/身高与全家中位数偏差 > 15% 报警（压扁等设计意图帧加白名单）

### 像素回归自检（qa_diff.py）

把源切图按管线同款变换铺回画布，与成品帧对齐搜索后量化 lost%：
- lost ≤ 1.7%：正常（边缘抗锯齿损耗）
- lost > 3%：先检查对比映射表本身（翻转/缩放参数错会产生假阳性），
  再用丢失掩码可视化确认是"整块缺失"还是"边缘虚化"

### 人工过目（不可省）

- **深底 + 浅底双背景接触表**：白发缺失在浅底完全不可见！
- 尺寸足够大（≥2x）逐帧过目，重点看：手持道具、鞋底、发丝边缘。

> **经验法则**：QA 全绿但用户仍看到破损 → 大概率是"深底才可见"的
> 白色部位缺失（白发/白鞋/白条纹），回②检查该区域的 alpha 值分布。

## ⑤ 运行时状态机（`pet.py`）

- tkinter 零第三方依赖；品红色键透明（`-transparentcolor`）
- 状态机按需扩展：待机/走路/快走/抓取/下落/落地/睡觉 + 彩蛋动作
- 进阶特性（本仓库已实现，可整段搬）：
  - **窗口即平台**：EnumWindows + DWM 可视边界枚举窗口顶边当平台，
    逐人裁切后角色可站在任意窗口上行走（Shimeji 式）
  - **单实例**：TCP 端口绑定（127.0.0.1:随机端口）。**不要用 CreateMutexW
    + GetLastError**——ctypes 下不可靠且僵尸句柄无法排查
  - **崩溃日志**：主循环 try/except 写 crash.log 到 exe 同目录
- 坐标一律 `int()` 后再进 `geometry()`（小数步速会让 x 变浮点，
  TclError 且被 after 回调静默吞掉）

## ⑥ 打包分发（PyInstaller）

```bash
python -m PyInstaller --onefile --noconsole --name IvenPet \
  --icon build_assets/icon.ico --add-data "frames3d;frames3d" pet.py
```

- 帧资源走 `--add-data` 打进 exe，运行时从 `sys._MEIPASS` 读
  （pet.py 已适配：`BASE = getattr(sys, "_MEIPASS", 脚本目录)`）
- `--noconsole`；图标用 IP 形象的 ico
- **重打包前必须杀掉运行中的实例**（onefile 文件锁）
- 产物 ~11MB，拷到桌面即双击可用

## MVP 快速版：只传一张三视图

不想凑齐全套 Sheet？一张三视图（正/侧/背，从左到右，任意背景）即可出**简化版**桌宠：

```bash
python tools/make_pet_from_views.py --src 路径/三视图.png --out frames3d_mvp
PET_FRAMES_DIR=frames3d_mvp python pet.py     # Windows: set PET_FRAMES_DIR=...
```

- 自动：任意背景通用粗定位 → 逐人 AI 抠图 → 侧视朝向检测（皮肤质心启发式，
  可用 `--side-faces left|right` 覆盖）→ 29 帧（呼吸压扁/程序剪腿步态/下落落地/
  抓取/睡觉/360°转体）
- 取舍：表情反应与真迈步循环为进阶能力（需补充对应 Sheet，走②③完整流程）；
  宠物脚本会自动隐藏缺失动作的菜单项，缺帧自动回退待机帧
- 自检：`python tools/qa_frames.py frames3d_mvp`

## 踩坑速查表（按症状索引）

| 症状 | 根因 | 修复 |
|---|---|---|
| 头发/白发成片消失 | 白发×白底，u2net 低 alpha 被单阈值砍 | 滞后阈值 140/25 传播生长 |
| 深色道具（板/鞋）残缺或消失 | u2net 丢手持道具 / 组件过滤误删 | 深色回收 + 组件阈值降至 2% |
| 道具白色细节透底 | 白条纹被判背景成透明洞 | fill_holes 回填封闭区 |
| 成品边缘紫/粉描边 | 重采样混入底色 | 预乘空间变换 + α≥160 二值化 |
| 某动作人物忽大忽小 | bbox 高度 fit 放大蜷缩姿势 | 头宽归一，缩放在 fit 后施加 |
| 走路双脚快速抽搐 | 两姿势交替帧率过高 | 帧 ≥500ms + 步幅匹配 |
| 双击 exe 没反应 | 已有实例在跑（单实例设计） | 正常；或查僵尸进程占端口 |
| QA 全绿但用户仍见破损 | 白色部位缺失仅在深底可见 | 深底接触表人工过目 |
