## Changelog

Comi Pet v2.2.0 ships five Halloween performances, a shared holiday menu across all three surfaces, an editable DSH plugin configuration page, and reliability fixes for Windows and the release pipeline.

### Downloads

| File | Platform | How to run |
| --- | --- | --- |
| `ComiPet-v2.2.0-windows-x64.zip` | Windows x64 | Unzip and run `ComiPet.exe`; no Python needed |
| `ComiPet-v2.2.0-macos-universal.zip` | macOS 13+, Apple Silicon / Intel | Unzip and open `ComiPet.app`; no Python or compiler needed |
| `SHA256SUMS.txt` | All | SHA-256 checksums for both archives |

The macOS build is ad-hoc signed and not notarized, so Gatekeeper may warn about an unidentified developer. You can also build from source following the README.

### New

1. **Five Halloween performances.** Collect candy in a pumpkin bucket, peek out from a ghost sheet, bow in a vampire cape, sweep with a witch hat, and play with a black cat and yarn. Each plush action has 15–16 discrete poses and lasts about 8–9 seconds at the shared 75% playback speed, with real pickup, costume and put-down poses preserved.
2. **One holiday menu everywhere.** macOS, Windows and the DSH overlay share the same **Actions → Holidays** grouping in both languages, including manual playback and autoplay. The five transparent preview GIFs and the combined preview are documented in the README.
3. **Reproducible action assets.** Source sheets, explicit crop boxes and ground marks, a unified-scale rebuild tool, source hashes and asset regression checks are included. The original 258 non-holiday PNG/GIF frames are unchanged; each performance keeps one scale throughout and starts/ends on the same neutral pose.
4. **Editable DSH plugin configuration.** `comi-bridge` now exports a schemastery `Config` schema, so the DSH webui renders all eight settings (events directory, summary, chat, chat directory, memory rounds, timeout, provider and model) with descriptions, defaults and range validation. If the host dependency cannot resolve under a symlinked install, it safely falls back to the existing `DEFAULT_CONFIG` with no behaviour change.
5. **Friendlier contribution entry points.** A pull-request template and code of conduct complement the existing issue templates and contributor guide.

### Fixes

1. **Halloween scale and cropping.** The character no longer suddenly grows and props are no longer clipped by the runtime canvas; a duplicated yarn-ball frame was removed from the black-cat sequence. The known large pixel jumps in deep bends and costume changes remain documented in the QA records — no cross-fade or distortion is used to pretend missing poses exist.
2. **Windows compatibility.** The Codex adapter's `--server-cmd` now uses POSIX `shlex.split` only on non-Windows systems, so backslashes in paths such as `D:\tools\...` are preserved. Home-directory tests also account for `USERPROFILE` on Windows; three macOS-only-passing cases now pass there too (150 passed).
3. **Release pipeline.** The retired `macos-14` runner image was replaced with `macos-15`; the earlier self-test retry based on a wrong diagnosis was reverted. Headless runners skip the GUI self-test, `publish` runs only for tag pushes, and `workflow_dispatch` performs build verification without requiring a tag or creating a release.

### Upgrade

- Quit the old app, then replace `ComiPet.app` or `ComiPet.exe`. Existing configuration and data are retained; no migration is needed. The built-in update check will point to this release.
- **DSH users must also update the plugin.** Update the repository and the installed `adapters/dsh/comi-bridge` directory, restart DSH and refresh its page. A symlinked plugin follows the repository update; a copied installation needs the complete updated plugin directory. The desktop ZIPs do not include adapters. See the [DSH setup guide](https://github.com/IvenKooLab/desktop-pet/blob/v2.2.0/adapters/dsh/README.md).

## 更新日志

Comi Pet v2.2.0 正式发布五组万圣节动作与三端统一的节日菜单，同时补齐 DSH 插件可视化配置、Windows 适配和发布流水线稳定性。

### 新增

1. **五组万圣节动作**：拿南瓜桶收糖、盖白布幽灵探头、披吸血鬼披风鞠躬、戴女巫帽挥扫帚、逗黑猫玩毛线。每组保留真实拿放与换装姿势，15–16 个离散姿势，按统一 75% 播放速度约 8–9 秒。
2. **三端统一节日菜单**：Mac、Windows 与 DSH 界面内均为「动作 → 节日」，中英文同步；支持单独点播，也加入自动轮播。中英 README 收录五组透明演示 GIF 与合辑预览。
3. **可复现的动作素材**：补齐原始动作图、显式切片框与地面标注、统一尺度重建工具、源图哈希和素材回归检查。原版非节日 258 张 PNG/GIF 保持不变；整段使用同一缩放，首尾共用同一中性站姿。
4. **DSH 插件可视化配置**：`comi-bridge` 导出 schemastery `Config` schema，webui 配置页可编辑全部 8 项配置（收件箱目录、摘要、对话开关、对话目录、记忆轮数、超时、provider、模型），带中文说明、默认值与范围校验。符号链接安装时若宿主依赖不可解析，则安全降级为原有 `DEFAULT_CONFIG`，行为零回归。
5. **贡献入口补齐**：新增 PR 模板与行为准则，与既有 issue 模板、贡献指南配套。

### 修复

1. **万圣节比例与裁切**：修复人物突然放大、道具被运行画布裁切；黑猫序列中重复毛线球的一帧已剔除。大幅弯腰、穿脱布料带来的相邻姿势像素跳变仍在 QA 记录中如实保留，不用交叉淡化或比例扭曲冒充缺失动作。
2. **Windows 兼容**：Codex 适配器的 `--server-cmd` 仅在非 Windows 走 POSIX `shlex.split`，保留 `D:\tools\...` 一类路径的反斜杠；家目录测试补齐 `USERPROFILE`。原先仅 macOS 能过的 3 个用例在 Windows 全绿（150 passed）。
3. **发布流水线**：已失效的 `macos-14` 镜像换成 `macos-15`，撤销此前基于错误归因的 self-test 重试；无头 runner 跳过 GUI self-test，`publish` 仅在 tag 触发，`workflow_dispatch` 只做构建校验、不要求 tag 也不会误发布。

### 升级

- 退出旧版后替换 `ComiPet.app` 或 `ComiPet.exe`，已有配置与数据继续沿用，无需迁移；桌宠内置更新检查会指向本版。
- **DSH 用户还需更新插件**：更新仓库及已安装的 `adapters/dsh/comi-bridge` 目录，再重启 DSH、刷新页面。符号链接安装随仓库更新，复制安装需重新复制完整插件目录。桌宠 ZIP 不包含适配器，详见 [DSH 接入说明](https://github.com/IvenKooLab/desktop-pet/blob/v2.2.0/adapters/dsh/README.md)。
- macOS 包为临时签名、未做 Apple 公证，系统可能提示无法验证开发者。
